# GEM300 Log Analyzer 기능 명세서

이 문서는 데스크톱 버전 기준의 현재 기능과 향후 추가 후보 기능을 정리한다.
기능이 추가되거나 동작 방식이 바뀌면 이 파일도 함께 갱신한다.

## 운영 기준

- 현재 개발 기준은 데스크톱 앱(`desktop_app.py`)이다.
- 웹/Streamlit 버전은 별도 요청이 있을 때만 수정한다.
- 배포 파일은 사용자가 명시적으로 요청할 때만 생성한다.
- 파싱 관련 코드 수정이 없으면 `tests\verify_parsing.py`는 실행하지 않는다.
- UI/스타일/배치 수정은 기본적으로 `python -m py_compile desktop_app.py`로 검증한다.

## 현재 구현 기능

### 로그 로딩/파싱

- MMI 로그와 SECS/GEM 로그 동시 로딩 및 통합 분석
- 여러 로그 파일 선택 및 드래그앤드롭 추가
- 파일 개수 기준 병렬 파싱
- 대용량 로그 안정성을 위해 파싱 스레드 수 최대 8개 제한
- 라인 수 계산은 1MB 바이너리 chunk 단위로 처리해 대용량 파일 메모리 사용 완화
- 로딩 중 진행 상태 표시
  - 총 라인 수
  - 분석 완료 라인 수
  - 진행률 progress bar
- Setup.ini 덤프 제외 옵션
- S6F11 CEID 제외 로딩
- S6F11 CEID 제외 목록 로컬 저장/복원
- MMI/SECS 시간이 동일한 경우 MMI 로그 우선 정렬

### 검색/필터

- 포함 키워드 목록
- 제외 키워드 목록
- 키워드 AND/OR 조건 지원
- 키워드 추가/수정/삭제
- 키워드 클릭 후 수정
- 키워드 선택 후 Delete 삭제
- 일반 문자열 검색과 정규식 검색 옵션
- 대소문자 구분 옵션
- S6F11 검색 시 S6F11W도 매칭
- SxFy 뒤의 W는 검색 결과에 영향 없도록 처리
- SxFy 메시지별 필터
- SxFy 필터와 포함/제외 키워드 조합 검색
- MMI/SECS 로그 타입 필터
- 북마크만 보기 필터
- 선택 로그 기준 시간 범위 빠른 필터
  - 앞뒤 1초/5초/30초/1분
  - 선택 시각 이전/이후
  - 기존 SxFy/키워드/북마크 필터와 함께 적용
  - 로그 세션 저장/복원에 포함
- 사용자 지정 시작/종료 시간 검색
  - `YYYY-MM-DD HH:MM:SS.fff` 또는 `HH:MM:SS` 형식 입력
  - 시작/종료 중 하나만 입력해 이후/이전 검색 가능
  - 시간만 입력하고 종료가 시작보다 빠르면 자정 넘어가는 범위로 처리
- 필터링 중 UI 멈춤 완화를 위한 백그라운드 필터 처리
- 필터링 진행 중 표시
- 검색 프리셋 저장/불러오기/삭제
- 선택 로그 기준 자동 연관 검색
  - 선택 로그에서 SxFy, CEID, 이벤트명, Carrier ID, Substrate ID/SubstID, Acquired ID, Port No, LocID 등 검색 후보 추출
  - 추출 후보를 AND 또는 OR 포함 키워드로 바로 추가

### 결과 테이블

- 통합 시간순 로그 표시
- 이전 로그와의 시간 간격 표시
  - 첫 행은 공백
  - 이후 행은 `+12ms`, `+3.4s`, `+2m 10s` 형태로 표시
  - 현재 필터 결과 순서 기준으로 계산
- 검색 결과 표시 행 수 제한
- 테이블 갱신 시 기존 row 일괄 삭제로 대량 결과 갱신 지연 완화
- 통계 패널 숨김 상태에서는 필터 결과 통계 집계 생략
- 컬럼 숨김/표시
- 컬럼 설정 로컬 저장/복원
- 컬럼 순서 드래그앤드롭 변경
- 컬럼 순서 로컬 저장/복원
- 헤더 hover/drag 커서 변경
- 북마크 행 강조 표시
- 선택 로그 원문 클립보드 복사
  - 검색 결과에서 연속/비연속 다중 선택 후 우클릭 메뉴로 복사
  - 각 로그 원문 사이에 빈 줄 1개 삽입
- 필터 결과 통계 패널 표시/숨김
  - 총 건수, MMI/SECS 건수, 북마크/Alarm 건수
  - Alarm 건수는 알람 추출 기준과 동일하게 집계
  - SxFy TOP 10, CEID TOP 10, 이벤트명 TOP 10
  - 현재 필터 결과 기준으로 자동 갱신
  - 표시 설정 로컬 저장/복원
- 로그 세션 저장/복원
  - 파일 목록, 포함/제외 키워드, 검색 옵션, 로그 필터 저장
  - 컬럼 순서/표시, 상세 보기 옵션, 북마크/메모 저장
  - DB/주석 설정과 S6F11 제외 설정 저장
  - 세션 복원 후 파일이 존재하면 바로 분석 실행 가능

### 상세 로그 보기

- 선택 로그 상세 표시
- 상세 로그 헤더 표시/숨김 옵션
- 현재 테이블에 표시 중인 컬럼만 상세 헤더에 표시
- 상세 로그 폰트/크기 변경
- 상세 로그 폰트/크기 로컬 저장/복원
- 긴 로그 줄바꿈 옵션
- 기본 상세 세로 보기
- 상세 가로 보기 옵션
- 로그 보기 전용 레이아웃
- 기본 레이아웃 복귀
- 선택 로그 기준 앞뒤 N개 로그 함께 보기
- 선택 로그 주변 같은 ID 흐름 강조
  - Carrier ID/Substrate ID/Acquired ID/Location ID/CEID/이벤트명 자동 추출
  - 앞뒤 N개 로그 상세 표시 범위에서 같은 값 자동 강조
  - ID 흐름 강조 사용 여부 로컬 저장/복원
- XML 포함 로그 예쁘게 표시
- 상세 로그 내 검색 키워드 하이라이트
- 검색/필터 결과 내 2차 검색
  - 현재 적용된 키워드, 제외, 로그 타입, 시간, 북마크, SxFy 필터 결과 안에서 추가 검색
  - 2차 검색어도 상세 로그 하이라이트와 매칭 키워드 표시 대상에 포함
- 상세 로그 스크롤바
- 상세 로그 텍스트 선택/복사

### 비교 기능

- 상세 로그 2개 선택 시 비교 보기 옵션
- Beyond Compare 형태의 라인별 비교
- 선택 라인 비교 패널
- 선택 라인 비교 상/하 표시
- 선택 라인 차이 문자 붉은색 강조
- 긴 비교 라인 가로 스크롤


### Carrier Roundtrip Timeline

- 현재 기본 비활성화: `CARRIER_ROUNDTRIP_TIMELINE_ENABLED = False`
- Carrier ID 입력 시 해당 Carrier 관련 상태 변화를 시간순 row로 표시
- row 선택 시 메인 로그 테이블의 원본 로그로 이동하고 상세 패널 갱신
- 재활성화 시 상세 로그 영역 크기 조절 동작도 함께 회귀 검증
- Carrier ID/slotmap read, LoadPort state, release, alarm/SECS 관련 로그를 timeline에 연결

### 분석 리포트

- Markdown/TXT 분석 리포트 내보내기
- 리포트 상단 원인 조사 힌트 표시
  - 로그 시간 범위
  - 최초 Alarm
  - 최초 Fail/Alarm 로그
  - 최초 문제 로그 앞뒤 컨텍스트와 이전 로그 대비 시간 간격
  - 문제 직전 주요 신호(SxFy, CEID/Event, Carrier/Substrate/Port 등)
  - 문제 직전 최대 시간 공백
  - TOP CEID/Event
  - TOP 매칭 키워드
  - 알람/GEM300 타임라인/검색 결과는 현재 리포트 대상 로그 범위 기준으로 집계
  - 필터 결과 0건이면 전체 로그로 되돌리지 않고 0건 리포트 생성
  - 저장 완료 상태 메시지에 리포트 대상 행 수 표시

### 실행/배포

- 데스크톱 실행 스크립트
- `run_desktop.bat` 실행 시 VBS/PowerShell hidden 실행으로 검은 콘솔창 표시 최소화
- 앱 실행은 가능하면 `pythonw.exe`를 사용해 GUI만 표시
- EXE 단일 실행 파일 빌드
  - `src/build_exe.ps1`로 현재 버전명 기반 EXE 생성
  - 산출물 위치: `src/dist/GEM300_Log_Analyzer_vX.Y.Z.exe`
- 오프라인 배포 패키지
  - Python/ODBC Driver 설치 파일은 포함하지 않음
  - 기존 설치된 Python으로 .venv 생성
  - wheelhouse 기반 오프라인 Python 패키지 설치
- 처음 설치용 스크립트
  - Python 3.14 환경 기준 오프라인 설치
  - `.venv` 생성
  - wheels 기반 오프라인 패키지 설치
  - 바탕화면 바로가기 생성

## 향후 추가 후보 기능

- 결과 내 검색 고도화
  - 결과 내 AND/OR 조건
  - 결과 내 제외 키워드
  - 결과 내 이전/다음 찾기
- 선택 row 기준 자동 컨텍스트 패널
  - 앞뒤 N초 또는 N줄 로그 별도 표시
  - 같은 Carrier ID/Substrate ID/CEID/SxFy 자동 강조
- Carrier/Substrate ID Flow 추적
  - 숨김 처리된 Carrier Roundtrip Timeline을 작은 범위의 ID 흐름 분석으로 재설계
  - Carrier/Substrate 관련 상태 변화를 시간순 목록으로 안정화
- Alarm 발생 전후 분석
  - Alarm 선택 시 이전 1분/5분/10분 주요 이벤트 요약
  - 직전 SxFy, CEID, LoadPort 상태, Carrier 관련 로그 추출
- 로그 패턴 즐겨찾기
  - Carrier Load, S6F11 Event, Alarm 전후, Port 상태 등 반복 조건 preset 제공
- 엑셀/CSV 내보내기 개선
  - 현재 필터 결과, 선택 row 주변 로그, 매칭 키워드 컬럼 포함
- 대용량 로그 성능 개선 후속
  - 검색 중 취소
  - 최근 검색 캐시
  - Treeview 가상 스크롤/페이지 단위 로딩
  - 파싱 중 진행률과 취소 기능 개선

## 버전 관리

- 버전은 `v1.0.0` 형태의 메이저.마이너.버그픽스 기준으로 관리한다.
- 기능 추가 시 마이너 버전을 올리고, 버그 수정만 있을 때는 버그픽스 버전을 올린다.
- 현재 버전은 `v1.5.0`이며 프로그램 제목에 표시한다.

## 문서 갱신 규칙

- 기능을 새로 추가하면 `현재 구현 기능`에 추가한다.
- 후보 기능을 구현하면 `향후 추가 후보 기능`에서 제거하거나 상태를 변경한다.
- 동작 방식이 바뀌면 기존 설명을 최신 동작 기준으로 수정한다.
- 배포 관련 변경이 있으면 `실행/배포` 항목을 갱신한다.
